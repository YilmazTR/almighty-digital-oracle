# Almighty Digital Oracle

A bilingual (EN/TR) self-discovery quiz that gives you a **zodiac sign** and a **personality type** in one reading. 46 questions, ~7 minutes.

## Features

- 2 intake + 24 zodiac + 20 personality-type questions
- Live "thinking" status bar
- **All data stored locally on your device** — nothing is sent to any server
- Optional history of past readings, viewable and exportable as JSON
- **Save your result as a shareable PNG** (rendered in-browser via Canvas)
- **Offline support** via a service worker (after first visit)
- Bilingual: English / Turkish
- Reduced-motion, keyboard, and screen-reader friendly
- No build step, no dependencies
